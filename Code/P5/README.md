This directory contains the code for the MF-SHRED - https://arxiv.org/abs/2606.05202.

There are three test cases:
- `Neutronics` (from the original conference paper from PHYSOR 2026 conference): from point kinetics to multigroup neutron diffusion
- `ReactionDiffAdvection`: from lumped model of a reaction advection diffusion system to the coupled PDE systems of species.
- `MSFR`: from lumped 0D model to the fully-coupled MP model in OpenFOAM (same dataset of P2)

The first and second cases require the `dolfinx` (version 0.10.0) to generate directly the data. The easiest way to install it this is through conda:

```bash
conda create -n dolf python=3.10
conda activate dolf
python -m pip install gmsh
conda install -c conda-forge fenics-dolfinx=0.10 mpich pyvista ipykernel scipy
```

The neutronics solvers have been updated from OFELIA repository within the ERMETE Lab.

Then, the data can be generated by running the associated notebook `01_generate_snaps.ipynb`. This will generate the diffusion data and store it in the `data` directory.

Alternatively, the npz can be downloaded from Zenodo.
